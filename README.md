# AI & Modern Tech Essentials Portfolio Repository

A comprehensive, hands-on portfolio repository demonstrating practical fluency across **Artificial Intelligence**, **Workflow Productivity**, **RAG Applications**, **Personal Branding Analytics**, **Defensive Cybersecurity Hygiene**, **Version Control Internals**, **Business Intelligence Dashboards**, and **Career Readiness**.

---

## Repository Structure

| File | Description |
| :--- | :--- |
| `01.ai_fluency.py` | Tokenization, term-frequency vector embeddings, cosine similarity, and structured prompt engineering templates. |
| `02.ai_productivity.py` | Automated task prioritization using the Eisenhower Matrix and regex-based meeting action-item extraction. |
| `03.ai_applications.py` | Lightweight Retrieval-Augmented Generation (RAG) pipeline with document ingestion, scoring, and grounded synthesis. |
| `04.linkedin_profile_analyzer.py` | Quantitative audit tool for LinkedIn profile sections with automated before/after visual comparison. |
| `04.profile_improvement.png` | Bar chart comparing profile optimization scores across Headline, Summary, Experience, Skills, and Projects. |
| `05.cybersecurity_toolkit.py` | Defensive security utilities for password entropy auditing, SHA-256 file integrity checks, and auth log review. |
| `06.mini_git.py` | Content-addressable version control simulator implementing blob hashing, staging, commit trees, and history logs. |
| `07.power_bi_dashboard.py` | End-to-end ETL pipeline cleaning raw sales records and generating a 4-panel executive analytics dashboard. |
| `07.sales_raw.csv` | Raw synthetic sales dataset containing missing values, unstandardized strings, and duplicate order entries. |
| `07.sales_clean.csv` | Cleaned, deduplicated, and enriched sales dataset with computed Gross Sales and Net Revenue metrics. |
| `07.sales_dashboard.png` | Multi-panel visual dashboard showing monthly revenue trends, category breakdowns, regional share, and rep performance. |
| `08.career_essentials.py` | Multi-axis career readiness evaluation script that generates a competency radar chart against industry benchmarks. |
| `08.career_skills_radar.png` | Polar radar chart mapping core technical and professional competencies. |
| `requirements.txt` | Python package dependencies required to run all scripts and regenerate visualizations. |

---

## Quick Start

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Individual Modules:**
   ```bash
   python 01.ai_fluency.py
   python 02.ai_productivity.py
   python 03.ai_applications.py
   python 04.linkedin_profile_analyzer.py
   python 05.cybersecurity_toolkit.py
   python 06.mini_git.py
   python 07.power_bi_dashboard.py
   python 08.career_essentials.py
   ```
